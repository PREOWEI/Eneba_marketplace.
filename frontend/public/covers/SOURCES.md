# Artwork sources

Verified on 2026-11-17. Exact URLs and product mappings are in `backend/data/product_covers.json`. Existing working artwork was preserved except for the requested GTA VI and Modern Warfare 4 replacements.

- GTA VI: official Rockstar portrait poster from the GTA VI website; saved as `grand-theft-auto-vi.jpg`. The stable product ID remains `gta-6-ultimate-edition`; the listing now represents Standard PS5, not an Ultimate PC key.
- Modern Warfare 4: official Standard Edition Box Art from the publisher's current game page, saved as `modern-warfare-4.webp`. The game is officially available, so it was not replaced with another Call of Duty.
- Gran Turismo 7: official PlayStation product image for Standard PS5, saved as JPEG (the remote .png URL returns JPEG).
- Halo Infinite: official Xbox campaign product 9PD22XJDR74N poster. The paid campaign is distinct from free multiplayer.
- Nine other new games: Steam library artwork verified against appdetails title IDs, downloaded as JPEG. These covers have no store or console branding; artwork source does not determine the listing entitlement. Each offer names one specific platform.
- Original Steam library images, EA Sports FC 27, NBA 2K27 and The Last of Us Remastered were retained. Square and portrait artwork uses the existing uncropped display rules.
- `fallback.svg` remains the neutral failure image. All 13 newly downloaded files returned HTTP 200 with an image MIME type and were visually inspected.

Artwork remains the property of its respective rights holders. Demo prices and regions describe sample inventory, not verified retail key availability or a redistribution license.
